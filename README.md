# quiet-relay

![status](https://img.shields.io/badge/status-wip-yellow)

POSIX-ish scripts for a single machine.

_Written to stay out of the way. Copy what you need._

## Features

- single purpose
- no telemetry
- readable diffs

## Usage

```bash
chmod +x bin/*
./bin/run.sh --help
```
